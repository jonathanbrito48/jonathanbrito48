### ⚙️ Padrões de Engenharia & Filosofia

- **Infraestrutura como Código (IaC):** Ambientes 100% declarativos e reprodutíveis via Terraform. Sem modificações manuais na console; esteiras automatizadas com GitHub Actions.
- **Segurança Cloud-Native:** Adoção de Zero-Trust por padrão, autenticação via Workload Identity Federation (sem chaves JSON estáticas) e governança centralizada com Secret Manager.
- **Engenharia de Software & Backend:** Python com tipagem estrita (Mypy), linting moderno (Ruff), Clean Architecture e isolamento de dependências.
- **Dados & Mensageria:** Pipelines analíticos com BigQuery e PostgreSQL, ingestão assíncrona desacoplada via Cloud Pub/Sub com Dead Letter Queues (DLQ) e estratégias de Backoff Exponencial.
